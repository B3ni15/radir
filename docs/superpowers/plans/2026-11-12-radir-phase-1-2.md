# Radír 1–2. fázis (alap, login és fiókok) – megvalósítási terv

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Egy iOS 18+ Radír app, amibe KRÉTA fiókkal (vagy demóval) be lehet lépni, több fiók között lehet váltani, és a fő tabok vázként megvannak, a Radír színeivel, iOS 26+-on Liquid Glass-szal.

**Architecture:** Egy Xcode projekt (`Radir.xcodeproj`, kézzel írt, Xcode 16+ szinkronizált mappákkal) app targettel és egy helyi Swift package-dzsel (`RadirKit`). Minden UI-független logika (színek, PKCE, KRÉTA auth, JWT, diákadat, fiókok tárolása, munkamenet) a `RadirKit`-ben van, és `swift test`-tel macOS-en tesztelhető. Az app target csak SwiftUI nézet és összekötés.

**Tech Stack:** Swift 6, SwiftUI, Observation, WebKit (`WKWebView`), CryptoKit, Security (Keychain), Swift Testing. Külső függőség nincs.

**Spec:** `docs/superpowers/specs/2026-11-12-radir-ios-design.md`

- Saját üveg csak `if #available(iOS 26, *)` mögött (`glassEffect`), különben `.regularMaterial`.

A scope-ok pontosan a legacyból: `openid email offline_access kreta-ellenorzo-webapi.public kreta-eugyintezes-webapi.public kreta-fileservice-webapi.public kreta-mobile-global-webapi.public kreta-dkt-webapi.public kreta-ier-webapi.public`.

- Demó intézménykód: `radir-demo`.

## Review Focus

1. Lejárt refresh token (`invalid_grant`): a fiók „újra be kell lépni” állapotba kerül, nem crashel, és a többi fiók megmarad. → Task 4: `refreshInvalidGrantThrowsReloginRequired`.
2. Két egyszerre induló kérés lejárt tokennel: csak egy refresh fut. → Task 5: `concurrentRequestsRefreshOnce`.
3. Ugyanaz a felhasználó kétszer lép be: nem lesz duplikált fiók, a tokenje frissül. → Task 6: `sameUserLoginReplacesAccount`.
4. A redirect URL-ben hiba van a kód helyett (`error=access_denied`), vagy más host: nincs kód, a login nem fogadja el. → Task 3: `redirectWithoutCodeIsIgnored`, `foreignHostIsIgnored`.
5. Hiányos `TanuloAdatlap` JSON (nincs `Bankszamla`, `Cimek`, `Gondviselok`): a diák ettől még betöltődik. → Task 4: `studentDecodesWithMissingOptionalFields`.
